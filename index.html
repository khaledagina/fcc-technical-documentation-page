JavaScript Starter Docs

The core ideas you need to start writing JavaScript for the web, with short examples you can paste into your browser console.

Introduction

JavaScript is the programming language of the web. It runs in every browser and lets a page react to what people do: clicks, typing, scrolling. These notes cover the basics I learned while studying front-end development.

To try any example, open your browser, press F12, choose the Console tab, and paste the code.

Before you start, it helps to know:

  • Basic HTML structure (tags, attributes).
  • Basic CSS (selectors, properties).
  • How to open a file in a browser and a code editor.
Variables

A variable is a named box that holds a value. Use const by default and let when the value will change. Avoid var in new code.

const city = "Mansoura";
let visits = 1;
visits = visits + 1;
console.log(city, visits); // Mansoura 2

Good names say what the value means. Use camelCase, like totalPrice.

Data Types

Every value has a type. The ones you will use most often:

  • string: text, such as "hello".
  • number: integers and decimals, such as 42 or 3.14.
  • boolean: true or false.
  • undefined and null: "no value yet" and "intentionally empty".
typeof "hi";   // "string"
typeof 10;     // "number"
typeof true;   // "boolean"

Tip: compare with ===, not ==. It does not convert types behind your back.

Functions

A function is a reusable block of code. It can take inputs (parameters) and give back an output with return.

function add(a, b) {
  return a + b;
}

const double = (n) => n * 2; // arrow function

console.log(add(2, 3)); // 5
console.log(double(4)); // 8

Keep each function focused on one job. If you cannot name it clearly, it probably does too much.

Arrays and Objects

An array is an ordered list. An object groups related values under named keys.

const skills = ["HTML", "CSS", "JavaScript"];
skills.push("React");

const student = { name: "Khaled", year: 2 };
console.log(skills.length, student.name); // 4 "Khaled"

Useful array methods:

  • map builds a new array by transforming each item.
  • filter keeps only the items that pass a test.
  • find returns the first item that passes a test.
[1, 2, 3].map(n => n * 10);      // [10, 20, 30]
[1, 2, 3, 4].filter(n => n % 2); // [1, 3]
Conditions and Loops

Use if to make decisions and loops to repeat work.

const score = 82;
if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("Keep going");
}

for (let i = 1; i <= 3; i++) {
  console.log("Round", i);
}

When you loop over a list, prefer for...of or an array method over a manual counter.

Working with the DOM

The DOM is the page as JavaScript sees it. You select an element, then change it or listen for events.

const button = document.querySelector("button");
button.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});

Always check that the element exists before using it, and keep style changes in CSS classes rather than inline styles.
